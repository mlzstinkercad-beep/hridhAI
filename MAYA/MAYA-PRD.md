# MAYA — Product Requirements Document (PRD)

**Document version:** 0.1
**Status:** Draft for hackathon prototype
**Product category:** AI That Protects — Voice Security / Anti-Spoofing
**Platform for MVP:** Android (Flutter + TFLite)
**Primary users:** App users (parents, students) and everyday call receivers
**Working tagline:** *We don't need AI to talk like us. We need AI to tell us when AI is pretending to be us.*

---

### 1. Executive Summary

MAYA is an offline, always-on mobile shield that detects AI-cloned and deepfake voices during live phone calls in under 4 seconds.

A mobile call can sound like your own child, but be generated by an AI. Users generally trust the voice they hear, while scammers can now clone a voice with 3 seconds of audio from social media. MAYA isolates the audio stream of a live call and verifies if the voice is human or synthetic, without ever uploading audio to a server.

A call is no longer just a call — every call must prove it is human.

### 2. Problem

1.  Voice cloning scams in India grew >300% (2024-25). Common attack: "Mummy, accident ho gaya" in child's cloned voice.
2.  Current apps (Truecaller, etc.) check phone NUMBER spam, not VOICE authenticity.
3.  All detection tools are cloud-based → privacy risk → can be hacked, audio can be leaked.
4.  Parents, students, elders have no simple RED/GREEN signal.

### 3. Goals and Non-Goals

**Goals:**
- Real-time detection: First result <4 seconds after call connects
- 100% offline inference - zero internet permission in manifest
- Always-on - No need to put on speaker or tap manually
- Explainable - Tell WHY it is fake (no breath, flat pitch, spectral artifact)
- Hacker-proof by architecture - No DB, no server, nothing to leak

**Non-Goals (V1):**
- Auto-blocking calls (only warns - user decides)
- iOS build (Android only for MVP due to Call Audio API)
- Video deepfake detection
- Storing or uploading call recordings

### 4. Users

- **Primary:** Parents / Guardians - Need simple color-coded safety.
- **Secondary:** Students / Everyday users - Get unknown calls.
- **Tertiary:** Developers / OEMs - Want to integrate MAYA SDK into their dialer app.

### 5. User Stories

- As a parent, I get a panic call that sounds like my child asking for money, I want MAYA to show a RED overlay if it's AI-generated.
- As a user, I want protection to work even in airplane mode, so I know my call data was never sent anywhere.
- As a user, when MAYA flags a call as cloned, I want to see 3 forensic reasons, so I trust it.
- As a developer, I want a single `Maya.scan(bytes)` function to add this to my own app.

### 6. Product Scope - MVP (48 Hours)

**P0 - Must Have:**
1.  Foreground Service `MayaGuardService` - Listens to call state
2.  Audio Capture - `AudioSource.VOICE_COMMUNICATION @ 16kHz Mono` in 3-sec sliding window every 2 sec
3.  On-Device Model - AASIST-Lite -> TFLite (Float16 quantized, ~22MB)
4.  Overlay UI - Floating pill over native dialer
5.  Privacy Vault - No audio saved, only text logs, buffer wiped after inference

**P1 - Nice to Have:**
6.  Explainability Engine: Breath / Pause / Spectrogram scores
7.  SDK: `maya-sdk.aar` for other devs
8.  Family Voice Print: Optional on-device enrollment of real family voice (stored as embedding, not audio)

### 7. Technical Architecture

```
[Android Telecom Framework]
         |
[MayaGuardService - Foreground + Accessibility + CallScreeningService]
         |
[Audio Module] -> AudioRecord -> NoiseSuppression -> MFCC/LFCC 3s window
         |
[TFLite Engine] -> NNAPI Delegate -> AASIST-Lite Inference <800ms
         |
[Decision Engine] -> Voting over last 3 windows -> Score 0-100
         |
[WindowManager Overlay] -> GREEN / RED Pill + Haptic + Alert Tone
```

**Model Stack:**
- Base: AASIST (Audio Anti-Spoofing with Spectro-Temporal Graph Attention)
- Trained on: ASVspoof 2019 LA + 200 custom Indian English/Hindi clones (ElevenLabs/PlayHT)
- Conversion: PyTorch -> ONNX -> TFLite FP16
- Size: ~22MB, RAM: <80MB

**Permissions:**
- `FOREGROUND_SERVICE`, `READ_PHONE_STATE`, `SYSTEM_ALERT_WINDOW`, `BIND_ACCESSIBILITY_SERVICE`
- Explicitly NO `INTERNET`, NO `RECORD_AUDIO` persistence, NO `READ_EXTERNAL_STORAGE`

### 8. UX Specification

**App States:**

**Idle:** Big shield. "Protected - 12 calls scanned today. Offline mode: Active"

**Scanning:** On incoming call, small pulsing pill top-center: "MAYA listening... 🔊"

**Verdict - REAL:** Pill -> Green. "✅ Real Human 96% - Breath pattern OK, Natural pauses"

**Verdict - CLONED:** Full red takeover + strong haptic + alert sound: "🚨 AI CLONED VOICE 91% - HANG UP. Call back on saved number. Reason: No breath, Flat pitch, Model artifact"

**Design System:** Black background, white text, only 2 accent colors: Green #00E676, Red #FF1744. Font: Inter Bold for alerts.

### 9. Privacy & Anti-Hacker Design

1.  **No Server:** APK has no internet permission. Cannot exfiltrate data even if hacked.
2.  **No Storage:** Audio buffer is in-memory circular buffer, wiped after 2 seconds. No .wav file created.
3.  **No Database to Hack:** Logs contain only timestamp + verdict, no audio, no number.
4.  **Auditable:** Open source model + TFLite file hash published. Anyone can verify.
5.  **On-Device Only:** All inference via NNAPI/GPU, no cloud fallback.

This is "Privacy by Design" - Microsoft Responsible AI principle.
